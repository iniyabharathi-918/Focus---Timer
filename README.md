Focus Timer
A tiny Pomodoro timer that runs in your browser. No install, no dependencies, one HTML file.
Live demo: https://YOUR-USERNAME.github.io/focus-timer/
Features
25-minute focus sessions, 5-minute short breaks, 15-minute long breaks
Start, pause and reset
Progress ring and session counter
Light and dark mode (follows your device)
Run it
Open index.html in any browser.
Publish it with GitHub Pages
Go to Settings → Pages
Under Branch, choose main and / (root)
Tap Save and wait about a minute
